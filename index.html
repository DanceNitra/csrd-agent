CSRD Reporting.
Postavený na oficiálnej EFRAG taxonómii.

iXBRL engine používa výhradne element names z oficiálnej EFRAG ESRS Set 1 XBRL Taxonomy (2023-12-22). 5,432 elementov overených. 0 vymyslených.

✅ Čo je hotové

  • Oficiálna EFRAG taxonómia stiahnutá a integrovaná
  • 33+ EFRAG element names — všetky overené v esrs_cor.xsd
  • Správny namespace: https://xbrl.efrag.org/taxonomy/esrs/2023-12-22
  • Správny schemaRef: esrs_all.xsd
  • Multi-year kontexty (2025 + 2024)
  • 6 firemných reportov s reálnymi dátami
  • SHA-256 audit trail ku každému reportu

⚠️ Čo ešte nie je

  • Nie je to certifikovaný ESMA ESEF filing — nemáme ESMA akreditáciu
  • Nie je to limited assurance — chýba audítorský partner
  • Dimenzie (Scope 3 breakdown, country, segment) — rozpracované
  • Hĺbka reportov — reálny ESRS report má 800–3,000 faktov, my máme 25–35
  • Nie je to náhrada za komerčný reporting tool (Workiva, Tagetik)

Čo CSRD Comply naozaj dokáže

Reálne možnosti — nie marketing.

◇

Oficiálna EFRAG taxonómia

Používame https://xbrl.efrag.org/taxonomy/esrs/2023-12-22 — rovnako ako EFRAG v ukážkových reportoch. 5,432 elementov, 60+ enumerations, linkbasy.

◆

Overené element names

Každý element name, ktorý použijeme, je skontrolovaný proti esrs_cor.xsd. 100% zhoda. Žiadne vymyslené koncepty.

◇

ESRS E1–G1 pokrytie

E1 (klíma), E2 (znečistenie), E3 (voda), E4 (biodiverzita), E5 (obehové hospodárstvo), S1 (zamestnanci), G1 (business conduct).

◆

Multi-year kontexty

Report generuje kontexty pre aktuálny aj predchádzajúci rok. Pripravené pre porovnávacie reportingy.

◇

SHA-256 audit trail

Každý report má kryptografický hash. Zmena čo i len jedného znaku je detekovateľná.

◆

Dimenzie (rozpracované)

Engine podporuje explicitMember a typedMember dimenzie. Scope 3 kategórie, time horizon, country — všetky definované, integrácia do dátových profilov prebieha.

✓

EFRAG ESRS Set 1 XBRL Taxonomy

Správny namespace, správne element names, správny schemaRef. Overené proti oficiálnemu balíku z EFRAG (30. 8. 2024).

✓

Inline XBRL 1.1

Štruktúra ix:header, ix:hidden, ix:resources, ix:nonFraction, ix:nonNumeric podľa XBRL International špecifikácie.

✓

XHTML výstup

Validný XHTML súbor s CSS štýlmi, čitateľný v prehliadači aj ako ESEF filing.

±

ESMA ESEF formát

Štruktúra zodpovedá požiadavkám RTS na ESEF, ale nie sme certifikovaný ESMA validátor. Pre oficiálny filing je potrebný ESMA-registrovaný nástroj (Arelle, etc.).

±

Limited Assurance ready

Report je pripravený na auditorské overenie — audit trail, dátové zdroje, compliance certifikát. Samotný limited assurance musí vykonať registrovaný audítor.

📊

Hĺbka reportov

Reálny ESRS report má 800–3,000 iXBRL faktov. My máme 25–35. Chýbajú:
→ Scope 3 breakdown (15 kategórií)
→ Target trajectories s baseline a milestone
→ Country breakdown pre S1 (employees per country)
→ Multi-year porovnanie v tabuľkách

🔗

Dimenzie a linkbasy

EFRAG definuje 150+ linkbas (presentation, definition, calculation, formula). My používame len základné kontexty. Pre plnú kompatibilitu treba linkbasy integrovať.

🔬

Validácia

Nemáme Arelle integrovaný (Python 3.11/3.12 nekompatibilita). Validujeme cez lxml. Oficiálna ESMA ESEF validácia vyžaduje Arelle alebo ekvivalentný nástroj.

🤝

Audítorský partner

Bez limited assurance od BDO, Grant Thornton alebo TPA nemá report právnu váhu. Hľadáme partnera na pilotné overenie.

📐

UI / Workflow

Engine je CLI nástroj. Nie je to webová aplikácia s drag-and-drop. Vyžaduje technické znalosti (Python, YAML, JSON).

📋

ESRS2 narrative

Identifikovali sme správne textové elementy v EFRAG taxonómii, ale mapovanie nie je úplné. Niektoré koncepty (napr. Corporate Culture Policy, Community Engagement) nemajú priamy ekvivalent v Set 1.

Máte CSRD povinnosť?

Po Omnibus I ~20 slovenských a ~50 českých firiem musí reportovať podľa ESRS. Náš engine je funkčný, používa oficiálnu EFRAG taxonómiu a je pripravený na ďalší vývoj.
